# Keydoze icon generation

Generated with the built-in ImageGen tool. Project-specific artwork; no reference brand assets are incorporated.

The artwork was generated under the working name Touchrest. The original prompt below is preserved verbatim.

## Prompt

Use case: logo-brand. Asset type: native macOS application icon for Touchrest, a small offline utility that pauses keyboard and pointing input while the user cleans their Mac. Create one finished square 1024 × 1024 icon on a genuinely transparent background. The icon is a single beautifully made, softly rounded physical keyboard keycap, viewed almost straight on with very slight dimensional perspective. Its face is rich desaturated jade / forest green enamel, with a soft sage edge highlight and a darker green lower bevel. Center a clear, large, warm ivory pause symbol consisting of two simple vertical rounded bars. Add one very small tasteful ivory glint near the upper-right edge, suggesting a freshly clean surface. Quiet premium Mac utility character; soft diffuse studio lighting, subtle tactile depth, crisp geometry, restrained highlights. Harmonize with a warm ivory light UI and charcoal-green dark UI. A single dominant silhouette that remains readable at 16 and 32 pixels. The rounded keycap fills about 85 percent of the square canvas, centered with even transparent clearance. No text, no letters, no keyboard grid, no extra objects, no laptop, no hands, no cartoon face, no blue/purple neon glow, no excessive glass, no watermark, no enclosing background rectangle. Deliver an actual transparent PNG, not a checkerboard depiction.
