# Changelog

## 0.2.0 — 5 November 2026

- Keydoze now updates itself. It checks once a day and asks before installing, and every update is signed. Turn automatic checks off in Keydoze > Settings…, or check any time with Keydoze > Check for Updates….
- Updates stay out of the way of a cleaning session: no check starts, no window appears, and no relaunch happens until input is back.
- Update checks and downloads go to GitHub. See the privacy policy for what GitHub can see.
- About now links to the privacy policy.

Coming from 0.1.0? It has no updater, so this is the one download you need to install by hand.

## 0.1.0 — 21 October 2026

- First notarized public release: Developer ID signed, accepted by Apple notarization, and stapled for Apple silicon Macs on macOS 26+.

- Clarify the combined input icon, start action, duration layout, spacing, and help affordance (0.1.0 build 3).
- Return cancelled preparation countdowns directly to setup.
- Explain the keyboard and trackpad cleaning purpose in the help sheet.

- Replace the scrolling About credits with a compact native window, concise privacy text, source and license links, and a single creator credit (0.1.0 build 2).

## 0.1.0-preview.1 — 6 September 2026

- Native macOS app for short keyboard and pointing-input cleaning sessions.
- Scope and duration choices, preparation countdown, automatic release, and early recovery.
- Independent deadline enforcement and interruption handling.
- Light and dark interfaces, original Keydoze icon, and accessibility fallbacks.
- Simplified access setup, larger duration choices, and short native selection and screen transitions.
- Offline operation with local preferences only.

The developer confirmed a successful physical laptop test on 6 September 2026. See [validation](docs/VALIDATION.md) for the current evidence and remaining hardware coverage.
